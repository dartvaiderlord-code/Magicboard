# magicboard

Системная Android-клавиатура для Android 8.0 и новее. Поддерживает русскую и английскую раскладки, эмодзи, цифры и символы. Подсказки и базовое автоисправление работают по встроенному словарю без сети. Автоисправление можно отключить в настройках приложения.

## Как пользоваться

1. Установите APK и откройте **magicboard**. Нажмите **Открыть настройки клавиатур**, включите magicboard, затем вернитесь в приложение и нажмите **Выбрать magicboard**.
2. Для обмена сообщениями сохраните одну и ту же длинную случайную фразу на обоих устройствах. Передайте её собеседнику по отдельному доверенному каналу. Фраза хранится в зашифрованном виде с ключом Android Keystore.
3. В чате выберите **Буфер**, наберите сообщение и нажмите **Зашифровать и вставить**. Открытый текст остаётся в клавиатуре. В поле чата появляется токен `ENC1:…`, который можно отправить кнопкой мессенджера.
4. Получатель может открыть токен в magicboard через меню **Поделиться** или **Расшифровать в magicboard**, если мессенджер поддерживает эти действия. Токен также можно вставить вручную на экране **Открыть шифротекст вручную**.

В обычном режиме клавиатура пишет напрямую в поле приложения. Экспериментальный **Live** работает в пустом поле и обновляет шифротекст по мере набора. Перед отправкой дождитесь статуса **Live: шифротекст готов**. Если мессенджер меняет поле или курсор в процессе, используйте **Буфер**. Закрытие клавиатуры или смена поля очищает приватный черновик.

## Автоматическая расшифровка

Отметьте нужные приложения в magicboard, прочитайте описание доступа, подтвердите согласие и включите службу **magicboard — показ расшифровки** в системных «Специальных возможностях». В списке есть Telegram, WhatsApp, Signal и Discord. Приложение обрабатывает видимые сообщения `ENC1:` в отмеченных приложениях и показывает расшифровку поверх них. В истории и на сервере мессенджера остаётся шифротекст.

Показ зависит от того, передаёт ли конкретная версия мессенджера полный токен в доступном элементе сообщения. При прокрутке или смене окна слой обновляется. Для сообщений, которые служба не распознаёт, доступна ручная расшифровка. Доступ можно отозвать в magicboard или в системных настройках. На некоторых устройствах Android для приложений, установленных из APK, потребуется отдельно разрешить ограниченные настройки.

## Сборка

Установите JDK 17 или 21, Android SDK Platform 35 и Android Build Tools 34.0.0. Откройте проект в Android Studio или укажите путь к SDK через `ANDROID_HOME`. Версия Gradle закреплена в Wrapper.

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions выполняет тесты и публикует APK как артефакт сборки.

## Формат сообщений

`ENC1:base64url(salt[16] | nonce[12] | ciphertext | tag[16])`. Используются AES-256-GCM, новая случайная соль и nonce на сообщение, PBKDF2-HMAC-SHA256 с 200 000 итераций. Аутентифицируемые данные `CipherBoard/ENC1` сохранены для совместимости с исходным прототипом. Приложение работает локально, без разрешения на интернет; приватные настройки исключены из резервного копирования. Криптографическая реализация не проходила независимый аудит.
